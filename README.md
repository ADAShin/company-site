# スカイライン・テクノロジーズ株式会社 コーポレートサイト

スカイライン・テクノロジーズ株式会社（Skyline Technologies, Inc.）のコーポレートサイトです。
ビルドツールやパッケージのインストールは不要で、`index.html` 1ファイルのみで完結します。

## ページ構成

1ページ完結のランディングページで、以下のセクションで構成されています。

- ヒーロー — canvas によるスカイライン（街並み）のアニメーション演出
- 私たちについて（`#about`）
- 事業内容（`#services`）— Webプロダクト開発、モバイルアプリ開発、クラウド・インフラ構築、AI・DXコンサルティング
- 選ばれる理由（`#strengths`）
- 進め方（`#process`）— ヒアリング・要件定義からリリース、運用・グロースまでの5ステップ
- 導入事例（`#works`）
- 会社概要（`#company`）
- お問い合わせ（`#contact`）

## 技術構成

- 素の HTML / CSS / JavaScript のみ（フレームワーク・依存パッケージなし）
- CSS と JavaScript は `index.html` にインラインで記述
- 表示用フォント「Big Shoulders Display」を Base64 で埋め込み（外部リクエストなしで表示）
- ライト / ダークテーマに対応。既定では OS の設定（`prefers-color-scheme`）に追従します
- `prefers-reduced-motion: reduce` が有効な環境ではヒーローのアニメーションを抑制

## ブラウザで開く手順

### 方法1: ファイルを直接開く（最も簡単）

外部通信を伴うリソースがないため、ファイルをそのまま開くだけで表示できます。

```bash
# macOS
open index.html

# Windows
start index.html

# Linux
xdg-open index.html
```

Finder / エクスプローラー上で `index.html` をダブルクリックする、
またはブラウザのウィンドウにファイルをドラッグ＆ドロップしても同様に表示できます。

### 方法2: ローカルサーバーで開く

本番に近い形（`http://` スキーム）で確認したい場合は、簡易サーバーを起動します。

```bash
# Python 3 の場合
python3 -m http.server 8000

# Node.js の場合
npx serve .
```

起動後、ブラウザで <http://localhost:8000> を開きます。サーバーを止めるには `Ctrl + C` を押します。

## 動作確認のヒント

- ダークテーマの確認は、OS の外観設定を切り替えるのが最も簡単です。
  個別に固定したい場合は `<html>` タグに `data-theme="dark"`（または `"light"`）を指定してください。
- レスポンシブ表示は、ブラウザの開発者ツール（`F12` または `Cmd + Option + I`）のデバイスモードで確認できます。
